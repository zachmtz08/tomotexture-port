# Legacy install scripts

These are the old Terminal-based installer files from before TomoTexture
shipped as a `.dmg`/`.app`. They're kept here for anyone who's mid-install
or scripting against them; **new users should use the `.dmg` from the
[latest release](https://github.com/zachmtz08/tomotexture-port/releases/latest)**.

These will be removed in a future release.
